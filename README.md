Protótipo navegável (HTML estático) do MERCATUS, marketplace de leilão reverso de
antecipação de recebíveis. Publicado via GitHub Pages apenas para compartilhamento
do link; não é produto e não indexa em buscadores (`robots.txt` + `noindex`).

- Entrada: **index.html** — mapa de todas as telas.
- Conteúdo gerado a partir do repositório de origem (`prototypes/v0.1/`, `publish_pages.py`).
  Não edite os arquivos aqui: eles são sobrescritos a cada publicação.
